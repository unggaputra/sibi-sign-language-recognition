Eksplorasi computer vision untuk deteksi tangan dan gestur Sistem Isyarat Bahasa Indonesia (SIBI) menggunakan Python, OpenCV, dan MediaPipe.

# Deskripsi

Proyek ini merupakan latihan penerapan computer vision untuk mempelajari pemrosesan citra dan deteksi tangan dalam konteks bahasa isyarat Indonesia.

OpenCV digunakan untuk mendukung pemrosesan citra dan video, sedangkan MediaPipe digunakan untuk mendeteksi tangan serta melacak landmark tangan. Dataset SIBI dari Roboflow digunakan sebagai sumber data untuk eksperimen terkait gestur bahasa isyarat.

# Teknologi
- Python - Bahasa pemrograman utama.
- OpenCV - Pemrosesan citra dan video.
- MediaPipe - Deteksi tangan dan pelacakan landmark.
- Roboflow - Sumber dataset SIBI.

# Dataset
Dataset yang digunakan adalah SIBI Dataset — Roboflow Universe, yang disediakan oleh SIBI Detection.

Informasi dataset:
- Jenis tugas: Object Detection.
- Versi dataset: 2.
- Jumlah gambar: sekitar 3.430.
- Jumlah kelas: 49.

Lisensi: CC BY 4.0.
Dataset mencakup berbagai kelas gestur, termasuk huruf dan kata dalam SIBI.

Sumber dataset: https://universe.roboflow.com/sibi-detection-nftzq/sibi-bieme/dataset/2/download

Penggunaan dan redistribusi dataset mengikuti ketentuan lisensi CC BY 4.0, termasuk kewajiban atribusi kepada sumbernya.

# Tujuan
- Mempelajari dasar pemrosesan citra menggunakan OpenCV.
- Mengeksplorasi deteksi tangan dan pelacakan landmark menggunakan MediaPipe.
- Memahami penerapan computer vision pada gestur bahasa isyarat.
- Mengembangkan kemampuan dasar dalam membangun sistem pengenalan gestur SIBI.
